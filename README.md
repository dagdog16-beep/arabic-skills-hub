# مجمع المهارات العربية — Arabic Skills Hub

**أول دليل عربي لمهارات وكلاء الذكاء الاصطناعي.**

كل مهارة هنا مجانية ومفتوحة المصدر، برابط GitHub وأمر تثبيت جاهز. الهدف بسيط: أن يجد المستخدم العربي — وصانع المهارات العربي — مكاناً واحداً يجمع المهارات التي تخدم العربية ولهجاتها وأهلها.

🌐 **الموقع:** https://dagdog16-beep.github.io/arabic-skills-hub/

## كيف تقترح مهارة؟ — Submit a Skill

المجمع مفتوح لمهارات المجتمع. لاقتراح مهارة:

1. افتح [Issue جديد](https://github.com/dagdog16-beep/arabic-skills-hub/issues) في هذا المستودع.
2. ضع رابط مستودع المهارة وشرحاً قصيراً لما تفعله ولمن تخدم.

**الشروط:**

- المهارة **مجانية** تماماً.
- المهارة **مفتوحة المصدر** برخصة حرة.
- المهارة **تخدم المستخدمين العرب** (لغة، لهجة، وصولية، أو حاجة عربية واضحة).

تُراجع الاقتراحات يدوياً، وما يستوفي الشروط يُضاف إلى الدليل.

## English

**Arabic Skills Hub** is the first Arabic-first directory of AI agent skills. Every listed skill is free and open source, with a GitHub link and a ready-to-paste install command.

- 🌐 Live site: https://dagdog16-beep.github.io/arabic-skills-hub/
- To submit a skill, open an [Issue](https://github.com/dagdog16-beep/arabic-skills-hub/issues) with your repo link and a short description. Skills must be free, open source, and serve Arabic users.
